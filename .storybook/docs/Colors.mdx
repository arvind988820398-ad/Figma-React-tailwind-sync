# Colors

Semantic color tokens, straight from the Figma **Themes** collection (export {auxokitDocs.tokens.themesExportedAt.slice(0, 10)}). The class name is the Figma variable name: `colors/background/bg-brand` is `bg-brand`. Only these classes are allowed for color; the default Tailwind palette is removed in strict mode, and `dark:` color overrides are never needed because every token switches with the theme and scheme.

## Backgrounds

## Text and icons
