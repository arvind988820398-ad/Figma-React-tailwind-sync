# AD Design Kit

AD Design Kit is a Tailwind-native design system that lives in Figma and ships as React + Tailwind CSS v4 code. Every Figma variable has a code twin with the same name, and every Figma component set has a React twin with the same variants. This Storybook is generated from the same registry the Figma sync uses, so what you read here is what is in Figma.

<SyncSummary />

## How this Storybook is organised

- **Foundations** — the token scales (colors, typography, radius, shadows) and the two themes (Modern and Enterprise) with light and dark modes. Use the **Theme** and **Scheme** toolbar menus to see every page re-render through the real Figma token modes.
- **Guides** — how to pick a component and how the Figma ⇄ code sync works, including every open drift finding.
- **Components** — one page per Figma component set: live stories with controls, the Figma property → React prop mapping, the recipe and when-to-use notes, and a link straight to the Figma set. The **Design** tab in the canvas shows the Figma frame next to each story.
